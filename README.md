Peruvian's Delight Atun Fix

A small server-side NeoForge mod that fixes the Atun entity from Peruvian's Delight.

What does it fix?

This mod fixes issues with the Atun entity's attributes that can cause errors when the entity is spawned or naturally generated.

The fix is applied server-side, so players do not need to install this mod on their clients.

Requirements
Minecraft 1.21.1
NeoForge 21.1.x
Peruvian's Delight 1.4.0
Installation
Install the required version of NeoForge on your server.
Install Peruvian's Delight 1.4.0.
Download the latest pd_atunfix release.
Place the .jar file in the server's mods folder.
Start the server.

The mod only needs to be installed on the server. Clients can join without installing Atun Fix.
